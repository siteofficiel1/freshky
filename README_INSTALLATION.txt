FRESHKY — SITE COMPLET POUR GITHUB PAGES

1. Décompressez ce ZIP.
2. Dans votre dépôt GitHub actuel, remplacez index.html et ajoutez le dossier assets avec tous ses fichiers. Conservez .nojekyll à la racine.
3. index.html doit être directement à la racine publiée, sans dossier supplémentaire.
4. Validez les modifications (Commit changes). Conservez votre configuration GitHub Pages existante.

POUR CHANGER LE NOM DANS LE LIEN
Le ZIP modifie le nom affiché, mais ne peut pas renommer le dépôt GitHub.
Dans le dépôt : Settings > General > Repository name : Freshky, puis Rename.
Si le dépôt est nommé exactement Freshky, l’adresse attendue est :
https://siteofficiel1.github.io/Freshky/
Catalogue : https://siteofficiel1.github.io/Freshky/#produits
Vérifiez ensuite Settings > Pages pour obtenir l’adresse publiée.
Sans renommage, le site Freshky fonctionne aussi à l’ancienne adresse /LAIT-DZ/.
Tous les chemins d’images sont relatifs et compatibles avec les deux noms.
