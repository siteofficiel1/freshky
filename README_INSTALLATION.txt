CE ZIP CONTIENT UN INDEX.HTML AUTONOME AVEC TOUTES LES PHOTOS INTEGREES.
Aucun dossier assets, aucun fichier JavaScript ou CSS supplementaire a envoyer.

PUBLICATION :
1. Creez un depot GitHub public (par exemple LAIT-DZ).
2. Decompressez ce ZIP sur votre PC.
3. Dans le depot, cliquez Add file > Upload files.
4. Envoyez les fichiers index.html et .nojekyll a la RACINE du depot.
   Vous pouvez aussi envoyer ce README_INSTALLATION.txt.
5. Cliquez Commit changes.
6. Settings > Pages > Deploy from a branch > main > /(root) > Save.
7. Ouvrez https://VOTRE-IDENTIFIANT.github.io/LAIT-DZ/
